## Findings and changes

1. Added a single WebPage entity per indexable page, referencing the existing shared WebSite and Organization IDs. Tool pages retain one application entity declaring SoftwareApplication and WebApplication. No invented reviews or ratings. Existing zero-price offers reflect the visible free-use statements. FAQ markup remains tied to visible FAQ data; FAQ rich-result eligibility is not promised.
2. Removed the hard-coded `PT1M` HowTo time: actual duration varies by file and device.
3. Replaced the wide social banner reference with `/opengraph-image`, generated statically at 1200×630 using existing Next APIs and PDFNova brand colors. No new dependencies. Existing favicons, logo and manifest retained.
4. Corrected tool privacy copy: signed-in results automatically upload to an account archive; availability ends after 30 days, but storage deletion is not scheduled. Source documents for local processing remain on-device. The existing Privacy Policy already explains retention. Removed a false claim that Word conversion never attaches output to an account, and the claim that PDF to Word is the only remote tool. Disclosed both analytics providers in shared tool copy. Clarified that demand-loaded libraries must load before offline use.
5. Added `noindex, nofollow` HTTP headers to backend responses, including binary downloads and errors, and frontend saved-files/auth/recovery responses. These are indexing controls, not authorization. Private content is protected by existing bearer checks, per-user filters and a private storage bucket. No document IDs, names or contents were added to SEO data. Temporary conversion directories and archive behavior were not changed.
6. Extended rendered verification to newer signup, recovery and saved-files routes; all public WebPage entities, image alt attributes and social metadata; query canonicals; visible tool FAQ questions; social PNG dimensions; private route headers; and trailing-slash normalization. The prior route inventory omitted signup/recovery/files links.
7. Fixed baseline lint blockers: Next-generated `next-env.d.ts` is excluded from lint, and an unused smoke-test variable and misplaced unused lint suppression were removed. Corrected a stale SEO test requiring an empty public contact URL: public endpoints are not credentials; verification/Supabase placeholders remain checked.
8. Removed a nested main landmark from the blog index, retaining its layout and content.
